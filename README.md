<h2 align="center">Professional Summary</h2>

Security Researcher focused on two complementary areas: <strong>Web3 Security</strong> and <strong>Web2 Application Security</strong>.

In <strong>Web3</strong>, my primary focus is smart contract and protocol security across DeFi, cross chain systems, blockchain infrastructure, consensus, governance, staking, oracle integrations, token accounting, share pricing, liquidation logic, bridge and message validation, replay protection, authorization boundaries, state transitions, economic invariants, reserve accounting and protocol liveness.

In <strong>Web2 AppSec</strong>, my focus is the security of web applications, APIs, backend services, authentication and authorization flows, input handling, parsers, logging and security sensitive integrations. Coverage includes Cross Site Scripting, SQL Injection, Remote Code Execution, Server Side Request Forgery, IDOR, BOLA, authentication bypass, authorization and access control flaws, command injection, path traversal, insecure file upload, XML External Entity, unsafe deserialization, Server Side Template Injection, CSRF, open redirects, business logic vulnerabilities and failures involving logging, serialization and malformed attacker controlled input.

The current public research record contains <strong>39 validated findings</strong> across audit contests and bug bounty programs, with <strong>4 final Critical</strong>, <strong>12 final High</strong>, <strong>11 final Medium</strong>, <strong>12 final Low</strong> and <strong>39 public technical writeups</strong>. The portfolio also includes <strong>1 public CVE in Apache Log4net</strong>.

My work emphasizes reproducible proofs of concept, real application and protocol paths, measurable security impact, explicit control cases, technically bounded claims and publicly verifiable evidence.
